Tất cả entities kế thừa BaseEntity:
  - Id: Guid (Guid.NewGuid() trong constructor — KHÔNG dùng DB auto-generate)
  - CreatedAt: DateTime (UTC, gán khi tạo)

Entities:

               TotalQuestions, TimeLimit, MaxTotalScore, PassingScore,
               ShowResultsImmediately, ShowAnswersAfterSubmission,
               AllowMultipleAttempts, MaxAttempts, IsPublished, PublishedDate

               Explanation, MaxPoints, DifficultyLevel(1-4)

Enums:

  - DocumentType: PDF, Word, Image, Video, Excel, PowerPoint, Other
  - ScheduleStatus: Pending, InProgress, Completed, Cancelled

[EduMind.Infrastructure.Data — Packages & Structure]  (SESSION 2)
================================================================================

NuGet Packages:
  - Microsoft.EntityFrameworkCore.SqlServer  10.0.11
  - Microsoft.EntityFrameworkCore.Tools     10.0.11

Project References: EduMind.Domain

Folder Structure:
  EduMind.Infrastructure.Data/
  ├── Contexts/
  │   └── ApplicationDbContext.cs      ← DbContext + auto-UpdatedAt SaveChangesAsync
  ├── Configurations/
  │   ├── UserConfiguration.cs         ← IEntityTypeConfiguration<User>
  │   ├── DocumentConfiguration.cs     ← IEntityTypeConfiguration<Document>
  │   ├── ScheduleConfiguration.cs     ← IEntityTypeConfiguration<Schedule>
  │   ├── QuizConfiguration.cs         ← IEntityTypeConfiguration<Quiz>
  │   └── QuestionConfiguration.cs     ← IEntityTypeConfiguration<Question>
  ├── Migrations/                      ← Tự sinh bằng dotnet ef migrations add
  └── DependencyInjection.cs           ← AddDataInfrastructure() extension

Cơ chế SaveChangesAsync (tự động UpdatedAt):
  1. ChangeTracker.Entries<BaseEntity>() lọc State = Modified
  2. entry.Property("UpdatedAt").CurrentValue = DateTime.UtcNow
  3. base.SaveChangesAsync() → SQL Server

Fluent API:
  - UserConfiguration:     Email UNIQUE index, Role as string, PasswordHash max 512
  - DocumentConfiguration: FK OwnerId→Users (Restrict), index on IsDeleted
  - ScheduleConfiguration: FK UserId→Users (Cascade), composite index (UserId, StartTime)
  - QuizConfiguration:     decimal(18,2) for scores, IsPublished index
  - QuestionConfiguration: nvarchar(max) for Content/Options, decimal(10,2) MaxPoints

Relationships:
  User (1) → (n) Document   [OwnerId FK, Restrict delete]
  User (1) → (n) Schedule   [UserId FK, Cascade delete]
  User (1) → (n) Quiz       [CreatedByUserId FK, Restrict delete]
  Quiz ←→ Question          [QuestionIds: JSON string — loose coupling]

DI registration (Program.cs):
  builder.Services.AddDataInfrastructure(builder.Configuration);

appsettings.json:
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Database=EduMind;Trusted_Connection=True;TrustServerCertificate=True;"
  }
